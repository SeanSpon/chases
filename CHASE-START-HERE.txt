AUTOCART FOR CHASE — WINDOWS PREVIEW

1. Open https://github.com/SeanSpon/chases/releases/latest
2. Under Assets, download AutoCart-Setup-0.1.1.exe.
3. Open the installer and follow the setup prompts.
4. Install Chrome or Edge if neither is installed.
5. Open AutoCart, add a product link, and click Start watching.
6. Close the window. AutoCart keeps watching in the system tray.
7. Right-click the tray icon to open, stop watching, or quit.

Keep the computer awake and connected to the internet.
This private repository requires GitHub access; Sean can send you the installer instead.
The installer is unsigned.

CURRENT LIMITATION: This preview watches stock and sends notifications.
It does not place real orders. Auto-buy checkout integrations are still pending.
Do not enter payment details into AutoCart.
